# 勞動基準法：事前預測（在跑檢索實驗之前寫下）

指令：`python selfcontain.py --auto --data data_law`（結果在 `results/selfcontain_auto_log.txt`）

| 長度 | 上下文增益（平均 ± 標準誤） | 正值比例 |
|---|---|---|
| 32 token | −0.000 ± 0.017 | 16/40 |
| 64 token | −0.030 ± 0.010 | 9/40 |
| 128 token | −0.046 ± 0.007 | 5/40 |
| 256 token | −0.020 ± 0.006 | 14/40 |

規則：選「上下文增益明顯小於 0（超過 2 個標準誤）的最小長度」。

**預測：勞動基準法最適合 64 token（約 100 字）。**
32 token 的增益接近 0、不是正的，所以預期 32 token 不會像 RP2040 那樣掉很多（RP2040 32 token 是 +0.044，檢索只有 20/32）。

測試題 `tests_law.py` 是在預測跑的同時、還沒看到預測結果前寫的，出題只看法條內容。
