# AromaOne X3 智慧咖啡機 使用手冊

> 本產品為虛構產品，本手冊僅供 RAG 系統示範使用。
> 型號：AO-X3-2026　製造商：香域家電股份有限公司

---

## 第一章 安全注意事項

1. 本機使用電壓為 AC 110V / 60Hz，額定功率 1450W，請勿與其他高功率電器共用延長線。
2. 沖煮過程中出水口溫度可達 92°C，請勿將手放在出水口下方。
3. 請勿讓 8 歲以下兒童單獨操作本機。
4. 清潔前請務必拔除電源插頭，並等待機器冷卻至少 30 分鐘。
5. 請勿將機身浸入水中或以水直接沖洗機身。
6. 本機需放置於平穩檯面，機身背面與牆壁距離至少 10 公分以利散熱。

## 第三章 各部位名稱

- **A. 上蓋與豆槽**：位於機器頂部，放入咖啡豆。
- **B. 研磨刻度旋鈕**：位於豆槽內側，僅可在研磨進行中調整。
- **C. 觸控面板**：位於正面，含 6 個飲品按鍵與 1 個設定鍵。
- **D. 出水口（可上下調整）**：高度可調整範圍 7～14 cm。
- **E. 蒸氣奶泡管**：位於右側，用於打奶泡。
- **F. 水箱**：位於左側，向上提起即可取出。
- **G. 渣盒與滴水盤**：位於正面下方，向前拉出即可取出。

## 第四章 首次使用

1. 取出所有包裝材料，以清水清洗水箱與滴水盤。
2. 將水箱注入飲用水至「MAX」刻度線，**請勿使用礦泉水或氣泡水**，以免造成水垢堆積。
3. 插上電源，按住電源鍵 3 秒開機。
4. 首次開機時，機器會自動進行「管路注水」，約需 90 秒，期間面板會閃爍藍燈。
5. 注水完成後，請在出水口下放置杯子，按下「熱水」鍵連續出水 2 次以沖洗管路。
6. 前 3 杯咖啡可能風味較淡，屬正常現象。

## 第五章 沖煮咖啡

### 5.1 基本操作
1. 確認水箱有水、豆槽有豆。
2. 將杯子放在出水口下方，並調整出水口高度。
3. 按下想要的飲品按鍵即可開始沖煮。

### 5.2 預設飲品容量

| 飲品 | 預設容量 | 可調整範圍 |
|---|---|---|
| 濃縮咖啡 | 40 ml | 25～80 ml |
| 雙倍濃縮 | 80 ml | 50～120 ml |
| 美式咖啡 | 180 ml | 120～300 ml |
| 拿鐵 | 240 ml | 180～350 ml |
| 卡布奇諾 | 200 ml | 150～300 ml |
| 熱水 | 200 ml | 50～400 ml |

### 5.3 調整濃度
按住飲品按鍵 2 秒可進入濃度調整模式，共有 5 段濃度（1 最淡，5 最濃），出廠預設為第 3 段。

### 5.4 使用咖啡粉
本機支援使用咖啡粉：打開上蓋旁的「粉槽蓋」，倒入**一平匙（約 7 公克）**咖啡粉，再按下飲品鍵。每次只能放一匙，放太多會造成堵塞。

## 第六章 打奶泡

1. 使用冰的鮮奶（建議 4°C 左右），倒至奶泡杯約 1/3 高度。
2. 按下「蒸氣」鍵，等待約 25 秒預熱，指示燈恆亮後即可使用。
3. 將奶泡管末端浸入牛奶表面下約 1 公分處，開啟蒸氣旋鈕。
4. 牛奶溫度到達 60～65°C 時關閉蒸氣（杯壁摸起來燙手但仍可握住）。
5. **使用完畢後，請立即以濕布擦拭奶泡管，並空噴蒸氣 3 秒**，避免牛奶殘留凝固。

## 第七章 App 連線（AromaLink）

1. 至 App Store 或 Google Play 下載「AromaLink」App。
2. 在機器上按住「設定鍵」5 秒，面板出現白燈閃爍即進入配對模式。
3. 打開 App，點選「新增裝置」，依照指示連接家中 Wi-Fi。
4. 注意：本機**僅支援 2.4GHz Wi-Fi**，若路由器為雙頻合一，請暫時分開兩個頻段。
5. 連線後可使用：遠端預約沖煮、自訂飲品配方（最多 8 組）、查看清潔提醒、韌體更新。

## 第八章 清潔與保養

| 項目 | 頻率 | 方法 |
|---|---|---|
| 渣盒、滴水盤 | 每日 | 清空並以清水沖洗 |
| 水箱 | 每週 | 以清水沖洗，勿用洗碗機 |
| 沖煮單元 | 每週 | 從右側門取出，以清水沖洗後自然風乾 |
| 奶泡管 | 每次使用後 | 擦拭並空噴蒸氣 |
| 除鈣 | 每 3 個月或面板亮起橘燈時 | 見 8.1 |
| 濾水芯 | 每 2 個月或 50 公升 | 更換新的濾水芯（料號 AO-F01） |

### 8.1 除鈣步驟
1. 將水箱倒空，加入 **500 ml 清水與 1 包原廠除鈣劑（料號 AO-D02）**。
2. 同時按住「熱水」與「蒸氣」鍵 5 秒，進入除鈣模式。
3. 除鈣程序約需 **25 分鐘**，期間請勿關機。
4. 完成後，水箱以清水沖洗，再裝滿清水，按下「熱水」鍵沖洗 3 次。

## 第九章 錯誤代碼與故障排除

| 代碼 / 狀況 | 可能原因 | 解決方法 |
|---|---|---|
| E01 | 水箱缺水或未裝好 | 加水並確認水箱確實卡入 |
| E02 | 豆槽沒有咖啡豆 | 補充咖啡豆，按任一鍵繼續 |
| E03 | 渣盒已滿 | 清空渣盒，取出後需等待 5 秒再裝回 |
| E04 | 沖煮單元未正確安裝 | 重新安裝沖煮單元直到聽見「喀」一聲 |
| E05 | 研磨器卡住 | 關機拔插頭，清除豆槽內異物，若仍無法排除請聯絡客服 |
| E07 | 機器過熱 | 關機靜置 30 分鐘後再使用 |
| E09 | 系統錯誤 | 拔插頭 1 分鐘後重新開機，若持續出現請聯絡客服 |
| 橘燈恆亮 | 需要除鈣 | 執行除鈣程序 |
| 咖啡太淡 | 研磨太粗或濃度太低 | 研磨刻度調細 1～2 段或提高濃度 |
| 咖啡出水很慢 | 研磨太細或需要除鈣 | 研磨刻度調粗，或執行除鈣 |
| App 找不到機器 | 使用 5GHz Wi-Fi | 改用 2.4GHz 網路 |
